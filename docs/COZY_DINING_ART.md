# Cozy dining art and validation

New raster asset: `client/assets/tilemap/cozy-decor-atlas.png`, RGBA 1536×1024. Created with the built-in image-generation tool, not the CLI. Its alpha is preserved. The renderer contains each cropped sprite proportionally; no stretching. The same atlas decorates a flat lavender title backdrop. Existing high-detail materials are retained on disk but no longer loaded into gameplay.

Final generation prompt:
> Use case: stylized-concept. Asset type: transparent sprite atlas for a cozy pixel-art fantasy cat tavern game. Generate exactly six isolated pixel-art decorations in a regular 3 column by 2 row atlas, equal cells, generous transparent gutters. Row one: a small lavender potion shelf with hanging sage herbs; a lavender arched moon window with pale butter-yellow stars; a potted sage-green trailing plant. Row two: a little purple wooden barrel; a small three-candle brass candelabra; a stack of pastel spellbooks with a tiny pink crystal. Style: genuine low-resolution 16-bit pixel art, deliberately chunky square pixels, limited pastel palette, flat two-tone shading and muted plum outlines, sweet cozy Stardew-like readability, NOT realistic, no fine grain, no gradients, no bloom, no saturated orange. Colors dusty lavender, sage, faded rose, cream, pale gold. Front/slightly top-down view, each object fully visible and not touching others. Transparent background. No text, no labels, no scene or floor. Designed to remain readable when each sprite is drawn only 32 to 60 pixels tall.

Floors, countertops, furniture and woven rugs use code-native pixel geometry in `client/tavern-renderer.ts`. This keeps visible furniture footprints identical to shared collision cells. The two upper seats are upholstered booths; the lower pair have wooden chair arms. Guests use the existing cat sprite sheet, with requested drinks in thought bubbles rather than already sitting on the table.

Validation: type check, production build, grid/collision/reachability tests, and two live Socket.IO clients covering ingredient collection, mixing, shared counter handoff, wrong-table rejection, correct-table delivery, advanced rhythm actions and shared pause. Browser inspection covers the title and active shift. NPCs currently appear/disappear at their assigned seats; walking arrival/departure animations are intentionally deferred.

Manual test: start a new shift, read the numbered ticket, gather its illustrated ingredients, complete mixing, optionally press Q at an empty kitchen counter, then carry the drink through the three-cell opening into the dining room. Stand beside the matching table and press E. A different table must retain the drink and explain the mismatch.
